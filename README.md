
# 🛡️ InvoiceGuard

### 🔗 Blockchain-Based Supplier Invoice Fraud Prevention

InvoiceGuard is a **blockchain-based invoice verification system** that helps detect duplicate invoices and securely track supplier invoice status using Ethereum smart contracts.

## ✨ Features

- 🔗 Blockchain-based invoice storage
- 🔍 Duplicate invoice detection
- ✅ Approve, reject, and mark invoices as paid
- 👛 MetaMask wallet integration
- 🔐 Supabase authentication
- 📊 Modern React dashboard

## 🛠️ Technologies

- **Frontend:** React.js, Vite
- **Blockchain:** Solidity, Hardhat 3, Viem
- **Wallet:** MetaMask
- **Authentication:** Supabase

## ⚙️ Requirements

- Node.js and npm
- Git
- MetaMask
- Supabase account

## 🚀 Installation

```bash
git clone https://github.com/Muskaan914/InvoiceGuard.git
cd InvoiceGuard
npm install
cd frontend
npm install
npm run dev
```

## ⛓️ Run Blockchain Locally

```bash
npx hardhat node
```

Deploy the contract:

```bash
npx hardhat ignition deploy ignition/modules/Invoice.ts
```
